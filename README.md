# Sorting Visualizer

Визуализация пяти алгоритмов сортировки со звуком: пузырьком, шейкерной, слиянием, вставками и Шелла.

**Видео:** https://youtu.be/8BMzMTtLCPs

## Как устроено

| Файл | Что делает |
|------|------------|
| `Sorting.c` | Сортирует случайный массив из 100 чисел и записывает состояние массива после каждого шага в `sort1.txt` … `sort5.txt` (одна строка — один шаг) |
| `render.py` | По этим файлам рисует кадры в `sortN_frames/` (изменённые элементы красные) и заставку `sortN_title.png` |
| `sound.py` | Делает звуковую дорожку `sortN.wav`: на каждый шаг звук, высота которого зависит от значения изменённого элемента |
| `build.sh` | Запускает всё по очереди и собирает видео `all_sorts.mp4` через ffmpeg |

## Запуск

Нужны `gcc`, Python 3 с Pillow и `ffmpeg`.

    bash build.sh
